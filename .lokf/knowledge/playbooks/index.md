# Playbooks

* [Regenerate and test the schema](regenerate-and-test.md) - How to change the github-actions schema: set up with uv and just, edit src/github_actions/schema/, regenerate with just gen-project, gen-doc, gen-merged and lokf-adapt, add examples, then run the checks CI runs (just test on Python 3.10 to 3.14, just lint and just lokf-adapt-check on 3.13) and the pre-commit hooks.
* [Release the schema](release.md) - How a releasing commit merged to main makes semantic-release promote the changelog's Unreleased section, tag vX.Y.Z and publish a GitHub Release, then dispatch the Knowledge Release workflow once KNOWLEDGE_RELEASE_ENABLED is true; below 1.0.0 from a v0.0.0 baseline tag, with a breaking change as a minor bump and nothing published to PyPI.
* [Validate data against the schema](validate-data.md) - How to check a YAML file against the github-actions schema with linkml-validate (for example with -C GhaReusableWorkflow), what the generated dataclass and Pydantic models check less, and the rules no tool checks, such as a repeated input_id or a read-all that does not stand alone.
* [Move the upstream pins](update-upstream-pins.md) - What to do when the upstream watch opens its issue: replace both SchemaStore files from one commit and move PINNED_COMMIT, the schema header's source and annotations and NOTICE; or read a newer REST API version's breaking changes and move PINNED_API_VERSION; tests/test_schema_rules.py checks that the header and the script agree on the pins and the reading date.
* [Knowledge sources map](knowledge-sources.md) - The librarian's scrape map: every repository location and external page this bundle derives concepts from, the concepts each yields, how to re-check each on a refresh run, and the paths left out on purpose.
* [Derive and check concepts from workflow files](derive-and-check.md) - How to run scripts/derive.py, which reads a repository's workflow and action files with yaml.safe_load and prints the GhaWorkflow, GhaReusableWorkflow and GhaAction frontmatter, the name of each check run the workflows' jobs report and the OpenSSF findings; with --check it exits 1 on drift from a knowledge bundle, and here it runs with --exclude tests/.
